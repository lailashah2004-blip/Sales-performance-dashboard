# Rollback Evidence

## Project
Sales Performance Interactive Dashboard

## Rollback Purpose
Rollback was prepared as a recovery approach in case the deployed Tableau dashboard introduced an issue or an unsuccessful version needed to be reverted.

## Rollback Approach
The rollback approach is to restore the previously working version of the Tableau dashboard/deployment.

### Rollback Steps
1. Identify the currently deployed version.
2. Identify the previously working version.
3. Revert the deployment to the previous working version.
4. Verify that the dashboard loads correctly.
5. Verify the interactive dashboard functionality.
6. Confirm that sales performance can still be viewed by product, region, and month.

## Verification
After rollback, the dashboard should be checked to ensure that:

- The dashboard opens successfully.
- Product-level sales analysis works.
- Region-level sales analysis works.
- Monthly sales analysis works.
- Interactive filters/functionality work correctly.

## Outcome
The rollback procedure provides a recovery method for restoring the dashboard to a previously working version if required.
