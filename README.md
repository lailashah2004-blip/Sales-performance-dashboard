# Tableau Sales Performance Dashboard

## Project Overview

This project is an interactive Tableau dashboard developed to analyze sales performance across different products, regions, and months.

The dashboard allows users to explore sales data interactively and identify sales trends and performance differences.

## Objectives

The main objectives of the dashboard are:

- Analyze sales performance by product.
- Compare sales performance across different regions.
- Analyze monthly sales trends.
- Provide an interactive and user-friendly dashboard.
- Support easier interpretation of sales performance data.

## Tools Used

- Tableau
- GitHub

## Dashboard Features

The interactive dashboard provides:

- Product-wise sales analysis
- Region-wise sales analysis
- Monthly sales analysis
- Interactive filters
- Visual charts and graphs
- Easy comparison of sales performance

## Outcome

The project resulted in an interactive Tableau dashboard that can be used to analyze sales performance by product, region, and month.

The dashboard provides a clear visual representation of the sales data and supports interactive exploration.
